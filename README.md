# Bloom & Joy

Магазин цветов на React и Vite: каталог, 3D-конструктор букета, корзина и оформление заказа. Заказы сохраняются сервером в SQLite и доступны в панели администратора.

## Локальный запуск

Нужен Node.js 24.12 или новее.

1. Скопируй `.env.example` в `.env` и измени `BLOOM_ADMIN_PASSWORD`.
2. В первом терминале запусти API:

   ```bash
   npm run api
   ```

3. Во втором терминале запусти сайт:

   ```bash
   npm run dev
   ```

4. Открой адрес, который покажет Vite. Панель администратора доступна по адресу сайта с `#/admin` в конце.

API работает на порту `3001`; Vite перенаправляет запросы `/api` на сервер. Файл базы создаётся автоматически по пути `data/bloom-joy.sqlite`.

## Панель администратора

Войди с паролем из `BLOOM_ADMIN_PASSWORD`. Панель показывает заказы, состав, контактные данные и доставку. Статус можно менять на «Новое», «Подтверждено», «В подготовке», «В пути», «Доставлено» или «Отменено».

Сеанс администратора истекает через 8 часов. После перезапуска API потребуется войти снова.

## Публикация

GitHub Pages публикует только фронтенд. Чтобы заказы с опубликованной страницы сохранялись в общей базе, API нужно отдельно разместить на хостинге Node.js с постоянным диском для файла SQLite.

После размещения API:

1. В настройках хостинга задай `BLOOM_ADMIN_PASSWORD`, `BLOOM_CORS_ORIGINS`, `BLOOM_DATABASE_PATH` и `PORT`.
2. В GitHub открой **Settings → Secrets and variables → Actions → Variables** и добавь `VITE_API_URL` со значением адреса API без `/api`.
3. Запусти workflow **Deploy to GitHub Pages** ещё раз.

Пока `VITE_API_URL` не задан, публичная страница сохраняет заказы только в браузере. Панель администратора сообщит, что API ещё не настроен.
